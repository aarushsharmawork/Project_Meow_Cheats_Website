# MeowCheats website

The standalone MeowCheats landing page. This repository contains only the website; extension code and releases remain in the extension repository.

## Local preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` from this folder, then open http://127.0.0.1:4173.

No installation or build is required.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, and save.

Expected address after deployment: https://aarushsharmawork.github.io/Project_Meow_Cheats_Website/
